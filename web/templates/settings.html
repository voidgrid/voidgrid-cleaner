admin notices

who gets tagged on discord when someone unlinked presses add me. a discord user ID. default: the server owner.

daily digest

a summary posted to discord once a day of what's going in the next day, plus a tech post for the admin channel if one is set. nothing is posted on a day with nothing to say. default: {{.DefaultDigest}} ({{.Zone}}).

log level

normal records who decided what, and each step of a deletion. audit also records every call the app makes to another service while acting: method, path and result. default: {{.DefaultLevel}}.

log expiry

entries in the log older than this are removed. default: {{.DefaultExpiry}} days; leave empty to use it.

library paths

every path plex, radarr and sonarr use, checked on each doctor run. verified means a file they list really is here. the doctor only looks inside, and only ever changes, paths you tick that are verified. music and photos can't be ticked.

mount each one into this container at the same path if you can. if one is mounted somewhere else here, put where under "mounted here at"; leave it empty when it's the same. a mapping covers everything under its path. saving starts a doctor run to check it.
